  - Creating Bookmarks in Word documents:
    1. Place your cursor where you want the bookmark
    2. Go to Insert tab
    3. Click Bookmark (in the Links group)
    4. Type a name for the bookmark (no spaces)
    5. Click Add
  - How to **JUMP** to a bookmark
    1. Press CTRL+G (or F5)
    2. In the left panel, choose Bookmark
    3. Select the bookmark name
    4. Click "Go To"
